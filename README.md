# skills

All the SKILL.MDs me and my agents use.

## canvas-art-pipelines

Use when generating artwork as code (p5.js sketches), especially with third-party
canvas libraries like [p5.brush](https://github.com/acamposuribe/p5.brush), or when
verifying canvas renders headlessly.

- [`canvas-art-pipelines/SKILL.md`](canvas-art-pipelines/SKILL.md) — main skill: paint-in-draw rule for WEBGL, headless pixel verification, CDN/file:// pitfalls.
- [`canvas-art-pipelines/references/p5-brush.md`](canvas-art-pipelines/references/p5-brush.md) — verified p5.brush quirks (large-circle crash, broken custom vector fields, prefix rules) and a known-good scene recipe.

## thribb-video

Use when asked for an explainer video, an animated math or science explanation, or a script and storyboard, in a teaching style studied from the 3Blue1Brown channel. Original wording and visuals only.

- [`thribb-video/SKILL.md`](thribb-video/SKILL.md) - main skill: concrete-first openings, honest simplification, motivated notation, color-bound equations, one persistent diagram.
- [`thribb-video/references/evidence-and-coverage.md`](thribb-video/references/evidence-and-coverage.md) - what was and was not reviewed when the method was studied.

## thribb-notes

Use when asked for illustrated notes, a lesson page, or a written companion to a video, in the same studied style. Original wording and figures only.

- [`thribb-notes/SKILL.md`](thribb-notes/SKILL.md) - main skill: concrete seed, pause-and-reveal exercises, figures tied to the prose by color, honest caveats.
- [`thribb-notes/references/evidence-and-coverage.md`](thribb-notes/references/evidence-and-coverage.md) - what was and was not reviewed.
