# Review before you call it done
Creator's rubric: motivation (whole topic and each step), clarity, novelty, memorability.
Page checks: (1) seed visible before any definition; (2) every term introduced after the picture it names; (3) every color means one thing page-wide; (4) each exercise has attempt space, reveal with worked answer, no leak; (5) caveats named; (6) every figure viewed as an image, text legible at column width, labels agree with the geometry and the prose; (7) no copied text or art; (8) coverage notes honest.
Common failures: abstract opening, symbol first, decorative figures, label/figure mismatch (see sample notes in this skill: an earlier version said 4x5 on a 5-wide, 4-tall figure and needed fixing), unexplained color changes.
