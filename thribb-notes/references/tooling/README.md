# Visual explainer tooling foundations

Verified 2026-10-17. This is an implementation component for two teaching skills, not a completed analysis of 3Blue1Brown's videos or written lessons.

- `references/engines.md`: exact tool identities, APIs, runtime constraints, and composition contracts.
- `references/upstream-skills.md`: upstream skill dependencies, with safe boundaries and pinned source provenance.
- `references/production-contract.md`: the bridge between a teaching storyboard and a reproducible visual artifact.
- `references/sources.md`: repository snapshots and license notes.
- `verification.json`: tests actually performed and limits.
- `examples/`: original small examples. The ManimGX and HyperFrames paths were rendered; CE and fframes are explicitly untested recipes.
- `evidence/`: decoded images from original renderer tests, not source-video captures.

These examples establish renderer operation and visible geometry, not learning effectiveness. They have no narration and do not establish an exact living creator's voice or visual style.

Do not infer that a recipe was run merely because its source is included. Do not infer that one Manim branch validates another. Preserve the verification labels when incorporating these files elsewhere.
